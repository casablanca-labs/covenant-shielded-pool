# M1 memory profile provenance

`memory-measure.py` is a byte-for-byte copy of the seal-era aggregate tool's
`memory-measure.py` at base commit `0303ec88`. Both files have SHA-256
`72bdf0b0037507310b363f6523a8659cd572b19be3cf5c5a7d1d4aff7b37a58e`.
The pool proof runner uses only its `env m1` mode. All modes were copied
verbatim; only `env m1` parity was checked. Provenance stays here so the
copied file remains byte-identical.
